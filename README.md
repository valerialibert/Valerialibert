# Olá, eu sou a Valéria! 👋💜

### 📡 Estudante de Tecnologia em Sistemas de Telecomunicações | UTFPR

Sou estudante da **Universidade Tecnológica Federal do Paraná (UTFPR)**, apaixonada por **telecomunicações, tecnologia, redes e sistemas de comunicação**.

Tenho interesse em desenvolver projetos que conectem **teoria e prática**, explorando áreas como **radiofrequência, antenas, satélites, redes IP, VoIP, eletrônica e automação**.

Este GitHub é o meu espaço para documentar estudos, compartilhar projetos e acompanhar minha evolução acadêmica e técnica.
