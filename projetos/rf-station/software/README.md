# Software planejado
Não há código implementado ou teste executado para o projeto nesta revisão documental.

Ferramentas previstas:
1. Frequência e comprimento de onda.
2. Aproximação de antena de quarto de onda.
3. Conversão W/mW/dBW/dBm.
4. Atenuação em cabo coaxial.
5. FSPL.
6. Orçamento de enlace e margem.
7. Horizonte rádio simplificado com hipóteses.
8. Gráficos de perda versus distância.
9. Cenários de altura usando modelo pertinente.
10. Análise de dados reais futuros.

Python será avaliado como ferramenta principal. Usar biblioteca padrão quando suficiente; NumPy para operações numéricas justificadas, Matplotlib para gráficos e pandas para dados tabulares quando necessário.

Requisitos futuros: comentários, unidades explícitas, validação de entradas, hipóteses, fontes, exemplos reproduzíveis, versões de dependências e verificações independentes. Testes poderão incluir conversões inversas e casos de referência, além de domínios inválidos; não se afirma aprovação de testes.
Dados hipotéticos, especificados, calculados e medidos serão separados. Não desenvolver código de transmissão ou firmware nesta fase.
